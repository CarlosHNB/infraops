// REGRAS DO JOGO

  • Não conte aula assistida como competência.
  • Todo mês termina com um GATE.
  • Todo lab deve gerar evidência: repo, comando, screenshot ou post-mortem.
  • Quando quebrar, não procure a resposta primeiro. Formule hipótese → teste → evidência.
  • CORE primeiro. Bônus só entra se o CORE estiver sólido.
  • O ISP Infrastructure Lab é o projeto-fio-condutor.
